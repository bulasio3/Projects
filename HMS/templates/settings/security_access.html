Security safeguards

Current protections built into account management.

Administrator-only access
Only authenticated administrator accounts can open this page or manage staff roles.
Password protection
New account passwords entered through staff management must be at least 8 characters. Passwords are stored using Django's password hashing.
Admin account protection
The system prevents an administrator from removing their own admin access and protects the last active administrator.
Role-based permissions
System pages enforce role checks on the server, not just by hiding navigation links.
